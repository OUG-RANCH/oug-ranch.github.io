# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase surfaces:** design tokens (CSS custom properties), header/nav (mobile hamburger drawer + desktop inline), full-screen hero with brand overlay + "ver coleções" CTA, collections anchor placeholder section, footer with Instagram, branded 404 page. **NOT in this phase:** collection cards (Phase 2), marquee/announcement bar (Phase 4). Site copy language: pt-BR (`lang="pt-BR"`), tone "amigo do interior" (branding.md §Tom de Voz).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — hand-written CSS with custom properties as the token layer (STACK.md: no Tailwind/PostCSS/build step) |
| Icon library | none — icons are CSS-drawn shapes (hamburger = 2 `<span>` lines), inline SVG (✕ close), or text glyphs with `aria-hidden` (→ ↓ ← ↗). No icon font, no CDN |
| Font | Yeseva One (400, display/headings) + Inter variable (400/600, body/UI), both self-hosted WOFF2 latin subset |

Font loading contract (D-07): `font-display: swap`; `<link rel="preload" as="font" type="font/woff2" crossorigin>` for **Yeseva One only**; Inter loads via `@font-face` without preload. Files: `fonts/yeseva-one-latin.woff2`, `fonts/inter-variable-latin.woff2`.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| `--space-xs` | 4px | Icon/text micro gaps |
| `--space-sm` | 8px | Compact element spacing (nav link letter gap, icon↔label) |
| `--space-md` | 16px | Default element spacing; **page gutter on mobile (<768px)** |
| `--space-lg` | 24px | Intra-section gaps, header vertical padding |
| `--space-xl` | 32px | Layout gaps; **page gutter on desktop (≥768px)** |
| `--space-2xl` | 48px | Major section padding (footer vertical) |
| `--space-3xl` | 64px | Page-level section breaks (hero↔placeholder, placeholder padding) |

Exceptions:
- `--touch-min: 44px` — minimum touch target for hamburger, drawer close, and all links inside the drawer (baked in now for PERF-03 later).
- `--header-h: 64px` — header height, mobile and desktop.
- Gutter token `--gutter: 16px` → `32px` at ≥768px media query.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (Inter) | 1.5 |
| Label | 14px | 600 (Inter) | 1.2 — uppercase, letter-spacing 0.05em (nav links, CTA, small section tags) |
| Heading | 28px | 400 (Yeseva One) | 1.2 — drawer links, section headings, 404 heading |
| Display | clamp(2.75rem, 11vw, 9rem) | 400 (Yeseva One) | 0.95 — hero wordmark only |

Exactly 4 sizes (14 / 16 / 28 / display-clamp), exactly 2 weights (400 / 600). Yeseva One ships only weight 400 — never synthesize bold on it. The clamp floor 2.75rem keeps the giant wordmark inside a 320px viewport.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F4F4EF` (creme) | Page background, header, drawer, footer, 404 page |
| Secondary (30%) | `#2B2623` (preto café) | All text, wordmark, hamburger lines, hairline rules (`rgba(43,38,35,.2)`), scrim base (`rgba(43,38,35,.55)`) |
| Accent (10%) | `#BB6F47` (caramelo) | See reserved-for list below |
| Destructive | none | No destructive actions exist in Phase 1; any future error copy renders in `#2B2623` |

Tokens: `--color-bg: #F4F4EF; --color-ink: #2B2623; --color-accent: #BB6F47;` plus `--rule: rgba(43,38,35,.2)` and `--scrim: rgba(43,38,35,.55)`. Verde `#7A9B5F` and azul `#2C4A6F` are **out of v1** (D-02) — do not define them as active tokens.

**Accent reserved for (exhaustive):** ① CTA "ver coleções" hover/focus fill; ② link hover/focus underline on desktop nav + footer Instagram link; ③ `:focus-visible` outline ring site-wide (2px, offset 2px). Accent is **never** used on body text, headings, logo, page backgrounds, or decorative blocks.

## Interaction Contracts (Phase 1 surfaces)

**Header** (NAV-01/03): static in normal flow (not fixed/sticky), background `--color-bg`, bottom hairline `1px solid var(--rule)`, height 64px, gutters per `--gutter`. Left: logo image from branding.md §LOGO (copied to `img/logo.png`, height 28px, `alt="OUG RANCH"`, links to `index.html`). Fallback if the extracted logo asset is unusable: wordmark text in Yeseva One 28px `#2B2623`. Right: mobile — hamburger button (44×44px, 2 CSS lines 20px wide × 2px thick, `#2B2623`); desktop ≥768px — inline nav links in Label role (14px/600/uppercase), hover shows 1px caramelo underline, hamburger hidden.

**Mobile drawer** (NAV-02): full-screen overlay panel, background `--color-bg`, slides from right (`transform: translateX(100%) → 0`, 250ms ease-out; `transition: none` under `prefers-reduced-motion: reduce`). Links in Heading role (Yeseva One 28px, `#2B2623`, ≥44px touch targets, stacked with 24px gaps). Close button ✕ (inline SVG, 44×44px) top-right. Open: hamburger `aria-expanded="true"`, `body { overflow: hidden }`, focus moves to the close button. Close via ✕, Esc key, or link tap; focus returns to hamburger. Closes automatically if viewport is resized to ≥768px.

**Hero** (HERO-01/02, A11Y-02): section `min-height: 100svh`, photo fills it via `object-fit: cover` — `<picture>` with `hero-mobile.webp` (portrait 4:5 crop, ≤900px wide) under 768px and `hero-desktop.webp` (landscape ≤1600px wide) above. Photo loads eager + `fetchpriority="high"`, carries explicit `width`/`height`, `alt` follows the documented convention (e.g. `alt="Campanha OUG RANCH — [descrição da cena]"`). Overlay scrim: `linear-gradient(to bottom, rgba(43,38,35,.55) 0%, rgba(43,38,35,.25) 45%, rgba(43,38,35,.45) 100%)` guaranteeing ≥4.5:1 contrast for the creme text regardless of the photo chosen. Wordmark overlay: `OUG RANCH` in Display role, `#F4F4EF`, top-left at gutters. Slogan below it, Body 16px `#F4F4EF`. CTA pinned to the hero's lower-left: transparent bg, `1px solid #F4F4EF` border, Label-role text in `#F4F4EF`, padding 16px 24px (≥44px tall); hover/focus → `background: #BB6F47; border-color: #BB6F47`. Tap scrolls smoothly (`scroll-behavior: smooth`) to `#colecoes` (jumps instantly under reduced motion).

**Collections placeholder** (scroll target for CTA): `<section id="colecoes">`, cream background, `padding: 64px 0`, small Label tag `coleções` + Heading 28px + placeholder body copy (see Copywriting) + Instagram text link (hover underline caramelo). No cards in Phase 1.

**Footer** (NAV-04, every page): background `--color-bg`, top hairline `var(--rule)`, `padding: 48px 0`, gutters per `--gutter`. Mobile: stacked; desktop: logo left / Instagram link right. Contains only the brand logo (height 24px) and the `@ougranch ↗` link — minimal per D-04.

**404 page** (`404.html`, Phase 1 success criterion 1): reuses header + footer, cream background, centered-left block: Heading 28px + body + recovery link (see Copywriting). No server tricks — plain static page.

**Global rules:** `:focus-visible { outline: 2px solid #BB6F47; outline-offset: 2px }` site-wide. `@media (prefers-reduced-motion: reduce)` → `scroll-behavior: auto`, drawer/marquee-class transitions none. Relative paths everywhere (`./css/styles.css`), classic `<script>` tags (PLAT-01), `.nojekyll` present. Files: `index.html`, `404.html`, `css/styles.css` (tokens at top = owner theme file), `js/main.js` (drawer + smooth scroll only).
